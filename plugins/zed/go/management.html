If CLIProxyAPI runs on another machine, the final 127.0.0.1 page will not load: paste its address here.
Add an account by importing its auth file Put a file of type zed in the auth directory, or upload it on the Auth Files page: 
{
  "type": "zed",
  "user_id": "12345",
  "access_token": "…",
  "system_id": "…",
  "organization_id": "org_…"
}
The token is the one Zed receives at sign-in; system_id is optional and derived from the token when absent.

Plugin settings

Bare IDs share routing with every other provider serving the same ID.
Zed exposes plan usage only to the dashboard. With this cookie and the account it belongs to, the Plugin tab shows that account's monthly spend and limit; the cookie is never sent to the LLM gateway.
