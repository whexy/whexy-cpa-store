Zed

Zed-hosted models through CLIProxyAPI.
Add an account
Click Start, then approve the sign-in in the browser. If CLIProxyAPI runs on another machine, the final 127.0.0.1 page will not load there: copy its address bar into the box below.
Add an account by importing its auth file
Put a file of type zed in the auth directory, or upload it on the Auth Files page: 
{
  "type": "zed",
  "user_id": "12345",
  "access_token": "…",
  "system_id": "…",
  "organization_id": "org_…"
}
The token is the one Zed receives at sign-in; system_id is optional and derived from the token when absent.
